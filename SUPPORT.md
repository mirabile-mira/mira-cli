# Support

## Getting Help

- **Bug reports and feature requests**: Open an [issue](https://github.com/Stewie-pixel/mirabile/issues).
- **General questions and discussions**: Use the [GitHub Discussions](https://github.com/Stewie-pixel/mirabile/discussions) tab if available, or open an issue with the `question` label.
- **Contributing**: See our [Contributing Guide](CONTRIBUTING.md) for how to get started.

## Before Opening an Issue

- Check [existing issues](https://github.com/Stewie-pixel/mirabile/issues) to see if your question or bug has already been addressed.
- Review the [Contributing Guide](CONTRIBUTING.md) for project setup and workflow instructions.

## Issue Guidelines

When opening an issue, please include:

- **For bugs**: steps to reproduce, expected vs. actual behavior, and relevant environment details (OS, Node.js version, browser).
- **For feature requests**: a clear description of the problem you're trying to solve and why the feature would be valuable.
- **For questions**: be specific about what you're trying to achieve and what you've already tried.

## Response Time

We aim to respond to issues within **one week**. Please be patient — maintainers are often working on the project in their spare time.
